# Roadmap

## Milestone 1: Browser Vertical Slice

- Runnable Vite app
- 3D synthetic airport scene
- Web Worker flight loop
- C172-inspired flight model
- keyboard and gamepad controls
- cockpit instruments and engine overlay

## Milestone 2: JSBSim WASM

- Emscripten build pipeline
- JSBSim runtime adapter
- C172 XML aircraft package
- automated validation fixtures

## Milestone 3: Real Scenery

- CesiumJS provider
- token/attribution UI
- OurAirports runway import
- generated airport detail
- quality presets and tile budgets

## Milestone 4: Simulator Depth

- live/deterministic weather
- radios and navaids
- checklists and failures
- replay/flight recorder
- additional aircraft packages

## Milestone 5: Packaging

- installable PWA
- offline app shell
- Electron builds for Windows, macOS, and Linux
